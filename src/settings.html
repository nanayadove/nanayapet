DuckDuckGo 免费无需Key；Tavily 免费1000次/月；Serper 付费（Google搜索）

知识库系统

自动从对话中提取事实、生成用户画像，去重后存入本地数据库。下次对话自动回忆。
事实提取和画像生成使用的服务商。"同对话"则复用对话API配置
建议用便宜的小模型节省成本。事实提取和画像生成共用此模型
每 N 条用户+助手消息自动触发一次后台事实提取，最小2、最大20
新事实与已有事实的相似度超过此值，不重复插入，改为更新置信度+0.1。值越低越容易合并
每次更新置信度时先按时间衰减：新置信度 = 旧置信度 × e^(-衰减率×天数) + 增量。0.01约30天后衰减到74%，0.05约30天后衰减到22%
累积超过此数量新事实后触发画像生成
距离上次生成超过此时间，且至少有少量新事实时触发
总事实数不足此值时不触发画像生成
每次对话最多注入几条相关事实到 LLM 上下文
每次对话最多注入几条相关知识到 LLM 上下文

主动搭话

让宠物不再只是被动回复，根据时间和概率主动发起话题。
上次活跃距现在超过此时间，启动时必定触发关心
每 N 分钟检查一次是否需要搭话
每次检查时触发搭话的概率，值越大越频繁
用户长时间不说话时，每次检查失败后概率自动增加此值
例如：基础15% + 每轮+10% → 第1轮15%、第2轮25%、依此类推直至触发
只要用户发言，概率立即重置回基础值
